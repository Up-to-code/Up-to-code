### 🛠 Developer tools

**[Kyna](https://github.com/Up-to-code/Kyna)** · [docs](https://up-to-code.github.io/kyna-docs/)  
A language I'm writing in C++. It has a compiler, bytecode VM, CLI, and VS Code extension. Still in development.

**[Sater](https://github.com/Up-to-code/sater)** · [sater.cc](https://sater.cc)  
I'm adapting Code - OSS for Arabic, with an RTL interface and support for working in Arabic and English.

### 📦 Install Kyna

```sh
npm install -g @kyna-language/cli
ky --version
ky doctor
```
